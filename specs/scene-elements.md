# Scene Elements

## Goal

Add dynamic foreground/background elements to make the scene feel more alive while staying minimal and toddler‑friendly.

## Requirements

- Add a small set of simple, animated or toggled elements (clouds, stars, trees, etc.).
- Elements should not clutter the screen or distract from the main truck.
- Behavior should be deterministic and lightweight (no heavy assets).

## Acceptance Criteria

- Elements render on desktop and mobile without layout issues.
- Performance remains smooth on low‑end devices.
- No persistence required.
