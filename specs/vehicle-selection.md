# Vehicle Selection

## Goal

Let kids switch between different vehicles (e.g., garbage truck, pink cybertruck) while keeping interactions consistent and simple.

## Requirements

- Provide a clear, child‑friendly way to change vehicle (touchable UI).
- Switching vehicles updates the visible truck without breaking existing interactions.
- Vehicle assets are lightweight and compatible with a static site.

## Acceptance Criteria

- User can switch vehicles on desktop and mobile.
- All existing interactions continue to work after switching.
- No new dependencies added unless essential.
